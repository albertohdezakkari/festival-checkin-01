Festival Check-in en local

1 · Arrancar 2 · CLI y SQL 3 · Invoke y API

1 · Arranca el proyecto

Usa Git Bash o Terminal con Node 22, Java 17 o superior y AWS CLI v2. Si ya tienes la carpeta, entra en ella y continúa con las dos terminales.

git clone --branch local https://github.com/albertohdezakkari/festival-checkin-01.git festival-checkin-local
cd festival-checkin-local
npm ci
mkdir -p .local/dynamodb
curl -fsSL https://d1ni2b6xgvw0s0.cloudfront.net/v2.x/dynamodb_local_latest.tar.gz | tar -xz -C .local/dynamodb

Terminal 1 · DynamoDB

Desde la raíz del clon, arranca DynamoDB Local en el puerto 8000. Los datos se guardan en .local/data.

npm run db:local

En este Mac, si Java de Homebrew está instalado y el sistema te dice que no lo encuentra, usa:

FCI_JAVA=/opt/homebrew/opt/openjdk@17/bin/java npm run db:local

Terminal 2 · Tablas y Lambdas

Desde la misma carpeta, crea las tres tablas y carga el evento 1 y usuario-02. Luego arranca Serverless Offline.

npm run datos:local && npm start

Busca Datos disponibles y Server ready: http://127.0.0.1:3004.

2 · Lee el mismo evento con AWS CLI y SQL

En otra terminal, define esta función de Bash. Usa credenciales ficticias durante el comando. --endpoint-url dirige la petición a tu DynamoDB local.

aws_local() (
  unset AWS_PROFILE AWS_DEFAULT_PROFILE AWS_SESSION_TOKEN AWS_SECURITY_TOKEN
  export AWS_ACCESS_KEY_ID=local AWS_SECRET_ACCESS_KEY=local
  aws --region us-east-1 --no-cli-pager "$@"
)

El SELECT que quieres expresar

SELECT *
FROM "FCI_EVENTOS_local"
WHERE EVENT_ID = 1

AWS CLI · GetItem

Envía la clave como JSON. N indica que 1 es un número.

aws_local dynamodb get-item \
  --endpoint-url http://127.0.0.1:8000 \
  --table-name FCI_EVENTOS_local \
  --key '{"EVENT_ID":{"N":"1"}}' \
  --query Item --output json

AWS CLI · PartiQL

Envía el SELECT en --statement. Items[0] muestra el primer resultado.

aws_local dynamodb execute-statement \
  --endpoint-url http://127.0.0.1:8000 \
  --statement 'SELECT * FROM "FCI_EVENTOS_local" WHERE EVENT_ID = 1' \
  --query 'Items[0]' --output json

Los dos comandos deben mostrar EVENT_ID = 1 y el título Festival de otoño.

Lista todos los eventos

Quita WHERE y muestra la lista Items.

aws_local dynamodb execute-statement \
  --endpoint-url http://127.0.0.1:8000 \
  --statement 'SELECT * FROM "FCI_EVENTOS_local"' \
  --query Items --output json

3 · Prueba Invoke y la API HTTP

Usa la terminal donde definiste aws_local. El puerto 3005 ejecuta invocaciones directas de Lambda. El puerto 3004 recibe peticiones de la API.

mkdir -p .local
aws_local lambda invoke \
  --endpoint-url http://127.0.0.1:3005 \
  --function-name festival-check-in-local-listarEventos \
  --cli-binary-format raw-in-base64-out \
  --payload '{}' .local/respuesta-listar.json
cat .local/respuesta-listar.json
url_inscripcion=http://127.0.0.1:3004/events/1/registrations/usuario-02
curl -i "$url_inscripcion"
curl -i -X POST "$url_inscripcion"
curl -i -X POST "$url_inscripcion"
curl -i "$url_inscripcion"

En una base recién preparada, ves 200 → 201 → 409 → 200. En la última respuesta aparece la inscripción. Si ya habías inscrito a ese usuario, los POST devuelven 409.
